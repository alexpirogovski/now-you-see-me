Avatar settings

Choose images for the ChatGPT overlay. Images are stored locally in this Chrome profile.

Idle avatar

PNG, JPEG, or WebP. Maximum file size: 5 MB.

Thinking avatar

Shown while ChatGPT displays its Thinking activity state. PNG, JPEG, or WebP; maximum file size: 5 MB. Falls back to the Answering avatar if unset.

Answering avatar

Shown while ChatGPT is generating a response. PNG, JPEG, or WebP; maximum file size: 5 MB. Falls back to the idle avatar if unset.
